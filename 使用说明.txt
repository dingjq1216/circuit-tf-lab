自动控制原理 · 电路求传递函数实验台
=====================================

一、启动（无需安装 Python 或任何环境）
  1. 双击运行 CircuitTFLab.exe。
  2. 程序会在本机起一个服务，并自动用默认浏览器打开实验台页面
     （默认地址 http://127.0.0.1:8848，若被占用会自动换用 8849、8850……）。
  3. 黑色命令行窗口代表服务正在运行；关闭该窗口即退出程序。

二、界面与用法
  1. 顶部「示例」下拉框内置 9 个电路，点选即可载入并自动求解：
       - RC 一阶低通 / 一阶高通（二端口画法）
       - RLC 串联谐振
       - 有源一阶低通（含放大器）
       - 双 RC 两级网络
       - PID 调节器（理想运放，I + P + D）
       - PD 比例微分校正（理想运放）
       - 串级双 RC（两级缓冲隔离，传函相乘）
       - 前馈电容补偿（零点超前）
  2. 左侧元件库拖动元件到画布：电阻 R、电容 C、电感 L、输入端口 U1、
     输出端口 OUT、放大器 AMP、理想运放 OPAMP、接地 GND。
  3. 连线：点击元件的一个引脚（出现高亮），再点另一个元件的引脚即可；
     点击导线可选中后按 Delete 删除。
  4. 选中与改参数：单击元件即可选中，左侧参数面板会一直显示，不会自动消失；
     双击元件同样会选中，并自动聚焦数值输入框，可直接键入新值再按 Tab 确认。
     旋转可用参数面板的「旋转 90°」按钮或按 R 键；删除元件按 Delete 键。
  5. 右侧会给出传递函数（符号式与数值式两种形式）、阶次、极点零点、
     稳定性判断，以及「复阻抗法」「电路方程法」两套推导步骤。
  6. 「信号仿真」页可切换阶跃 / 方波 / 斜坡 / 加速度 / 正弦激励，
     查看输入输出波形与超调量、上升时间、调节时间等指标。
  7. 画布操作：滚轮缩放、空白处按住拖动平移、「适应窗口」按钮复位视图。

三、内置示例的结论（可用于课堂对照）
  - PID（R1=R2=10 kΩ，C1=C2=1 μF）：
        H(s) = -(C1C2R1R2 s² + (C1R1+C2R2)s + 1) / (C2R1 s)
        = -(0.01 s² + 2 s + 100) / s
        即 Kp = 2、Kd = 0.01、Ki = 100（反相型理想 PID）。
  - PD（R1=1 kΩ，C1=1 μF，R2=10 kΩ）：
        H(s) = -(R2/R1)(1 + R1C1 s) = -(10 + 0.01 s)
  - 串级双 RC（两级各经增益 1 的缓冲隔离）：
        H(s) = (1000/(s+1000))² = 10⁶ / (s² + 2000s + 10⁶)
  - 前馈电容（C = 1 μF 与 R1 = 1 kΩ 并联，再接 1 μF 到地）：
        H(s) = (0.5 s + 500) / (s + 500)，前馈零点使相位超前。

四、说明与提示
  - 服务只监听本机 127.0.0.1，不联网、不上传任何数据。
  - 理想运放采用「虚短」模型：V+ = V−，输入端不取电流，输出电流由外电路决定；
    因此可搭反相比例、积分、微分、PID 等反馈电路。
  - 带理想微分的电路（如 PID/PD）属于非真系统（分子阶次不低于分母），
    仿真时会自动附加高频极点近似，并给出提示，属正常现象。
  - 若杀毒软件拦截，请将本文件夹加入信任列表后再运行。
